# Bilder

Hier gehoeren die eigenen Fotos hin. Solange eine Datei fehlt, zeigt die Seite
im Rahmen, welches Motiv dorthin gehoert – sie sieht dadurch absichtsvoll aus
und nicht kaputt.

| Datei | Motiv |
|---|---|
| `portrait.jpg` | Halbnah, harte Lichtkante, ernst. Nicht das Bewerbungsfoto. Traegt die halbe Seite. |
| `ausdauer-01.jpg` | In Bewegung, Seitenprofil, Gegenlicht. Kein Zielfoto mit Startnummer. |
| `ausdauer-02.jpg` | Landschaft, du klein im Bild. Zeigt Distanz statt Leistung. |
| `ausdauer-03.jpg` | Detail: Schuhe, Rad oder Uhr mit Daten. Die Bruecke zum Analytics-Teil. |
| `ausdauer-04.jpg` | Nach der Einheit: ehrlich, verschwitzt, kein Posieren. |

Querformat, mindestens 1600 px breit. Danach die Pfade in `_data/profile.yml`
und `_data/sport.yml` eintragen.

Portrait und Bandfotos werden aktuell von stephanjacobs.de bzw.
the-royal-flash.de geladen. Fuer den Dauerbetrieb besser hierher kopieren und
die Adressen in `_data/profile.yml` und `_data/band.yml` austauschen.
